# 隐私清理与验收

## 范围

公开源码与远端所有分支/标签清除个人账户路径、作者注释、固定签名主体、IDE/Finder 状态、真实环境截图及旧发布包。远端历史按同一规则重写，并使用项目署名。本地原 main 的文件、未提交修改和历史保留，不向远端重新上传。

运行时凭据迁移至 Keychain；AI 外发默认关闭，用户明确保存授权后才允许向对应 HTTPS 服务发送已说明的应用元数据。所有请求统一去除个人目录、邮箱和凭据文本；日志不输出服务地址和响应正文。本地缓存继续支持应用功能，提供明确的数据保存说明。

## 验收方案

| 编号 | 前置条件与操作 | 通过标准 | 验证方式 | 状态 |
| --- | --- | --- | --- | --- |
| P01 必验 / 源码 | 清理当前分支后扫描跟踪文件 | 无真实个人标识、绝对个人路径、IDE 状态、截图或旧签名包 | 自动扫描 + 人工复核 | 通过：清除 IDE/Finder 状态、真实截图和旧安装包；自动模式及已知身份复核无命中。 |
| P02 必验 / 凭据 | 使用隔离 UserDefaults 和替身 SecretStorage | 成功迁移后移除旧值；失败不丢凭据；UI 不显示明文 | 单元测试 + 两套 UI 编译 | 通过：隔离偏好域 + MemorySecrets 替身测试迁移、失败保留、删除凭据；SecureField 与两套 UI 编译通过。未访问真实用户钥匙串。 |
| P03 必验 / AI | 隔离配置测试未授权、服务变更、非 HTTPS、敏感文本 | 请求前拒绝未经授权外发；个人路径/邮箱/Key 不进入请求正文 | 单元测试 + adapter 入口检查 | 通过：URLProtocol 替身验证未授权不请求、正文脱敏和服务器错误不泄露响应；禁用自动重定向、Cookie 和请求缓存。未调用真实 AI。 |
| P04 必验 / 兼容性 | 修正后构建 Swift Package DIRECT/MAS 与 Xcode | 两套应用编译通过，隐私回归测试通过 | swift build/test、xcodebuild | 通过：完整 Xcode 工具链下 12 项 Swift 隐私测试 0 失败；DIRECT/MAS 和 Xcode Debug 无签名构建通过。原生设置界面未做运行时视觉验收。 |
| P05 必验 / 站点 | 展示合成演示图和撤下下载状态 | 不含真实截图、虚假下载按钮或旧包回退；桌面/移动正常 | 独立浏览器测试，结束后关闭会话 | 通过：1280×900 与 390×844 浏览器检查无横向溢出、无失效图片/旧包入口、控制台无错误；独立会话已关闭并核实进程退出。 |
| P06 必验 / 历史 | 在隔离副本中重写全部远端 heads/tags | 所有可达提交的内容、路径、作者/提交者/消息符合清理规则 | 完整历史对象扫描 | 通过预发布检查：隔离镜像重写后 12 个历史提交、109 个独立 blob 无已知身份或禁止文件命中；待加入当前修正并远端复查。 |
| P07 必验 / 远端 | 发布后重新克隆并枚举 Release/Actions/Pages | main/openDock/标签历史干净，旧附件及审计范围内的旧构建资源移除 | Git 与 GitHub API 实查 | 待执行 |
| P08 必验 / 本地保护 | 对比原 main 的文件哈希、状态与 HEAD | 与操作前快照一致 | 本地快照比对 | 通过预发布检查：本地原 main 的 114 个原有文件内容不变；另有并行操作更改 .gitignore/Finder 元数据、HEAD 与暂存状态，已保留并建立发布前快照。 |

GitHub 不可达对象的服务器回收、网页缓存、他人 fork/克隆不在 Git 推送控制范围内，最终报告会区分已验证的远端引用与这些限制。生产发布、真实 AI 调用和真实用户凭据/缓存读取不属于本次验证。

## 本轮交付

- 两套 Swift 源码：钥匙串凭据、AI 授权与发送过滤、禁止重定向、去除敏感日志、独立缓存目录及本机记录开关/清除。
- Xcode 配置：移除固定个人团队，使用项目 Bundle ID；同步脚本从自身位置确定项目路径。
- 站点：使用合成 SVG 演示图，撤下旧下载入口和个人仓库硬编码。
- Tests/PrivacyTests：12 项隔离回归测试；scripts/check-privacy.py 与 CI 防止个人路径、凭据和本地产物重新入库。
- 隐私说明见 PRIVACY.md；旧审计报告中的个人身份文件名不再公开保存。

技术验证通过不代表视觉/业务认可或正式签名发布完成。
